CampusX

Multi-LLM consensus aggregation engine for zero-hallucination query resolution

Problem

Researchers and students receive inconsistent or hallucinated answers when querying a single LLM without independent verification.

What I built

Co-developed an asynchronous FastAPI gateway that fans out prompt RPCs simultaneously across multiple model providers, evaluates semantic agreement via cosine distance, and aggregates consensus responses.

What I'd do differently

I would replace client-side polling with persistent Server-Sent Events (SSE) to stream intermediate agreement scores token-by-token as individual provider streams complete.

Competed at HackSRM 2026 Parallel async dispatch across diverse LLM APIs Dynamic cosine similarity and token voting

VOCA

Real-time speech evaluation and conversational language learning companion

Problem

Language learners lack affordable, immediate feedback on pronunciation cadence, accent divergence, and contextual conversational dialogue.

What I built

Built an interactive speech evaluation platform utilizing the Web Speech API to capture live audio cadence, route phonetic buffers into an LLM scoring pipeline, and persist session metrics to Firebase.

What I'd do differently

I would integrate a client-side WebAssembly phoneme classifier to execute phonetic analysis offline without depending on browser-specific speech synthesis engines.

IPL Mega Auction Platform

Real-time multiplayer simulated cricket franchise auction with live bidding mechanics

Live
Problem

Multiplayer auction simulations frequently suffer from race conditions, duplicate high bids, and purse overdrafts under simultaneous client updates.

What I built

Designed an event-driven bidding engine powered by Firebase Realtime Database using atomic transaction locks to validate purse balance constraints and broadcast updates under 50ms.

What I'd do differently

I would migrate stateful auction synchronization to an Elixir/Phoenix channel cluster or Redis Pub/Sub backend to support thousands of concurrent spectator connections per room.

Deployed live on Firebase Hosting Sub-50ms synchronized state across connected clients Zero purse race conditions via atomic transaction guards

About

I am an undergraduate in Computer Science & Engineering with a specialization in Artificial Intelligence and Machine Learning at SRM University AP (2025–2029, current CGPA: 8.2).

My engineering focus is centered on applied intelligence and distributed web architectures: building asynchronous multi-agent inference pipelines, designing low-latency API gateways, and implementing reliable real-time state synchronization. I prefer shipping tools that resolve real friction rather than wrapping APIs in speculative user interfaces.

Outside code, my approach to problem-solving is shaped by four long-standing disciplines:

  • Cinema: Studying scene pacing, editing rhythm, and visual economy translates directly to how I structure user experiences and interface transitions.
  • Cricket: Playing competitively reinforces situational awareness, team communication, and the discipline to execute fundamental mechanics under time pressure.
  • Competitive debate: Testing propositions against first principles trains me to defend technical architectural tradeoffs with concrete evidence rather than dogma.
  • Acoustic music: Listening to analog, unadorned arrangements provides a quiet backdrop for deep technical focus and iterative refactoring.
