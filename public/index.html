RootMap

An interactive map and directory of India's political and administrative geography.

Context

India's political and administrative information—executive cabinets, Article 246 Seventh Schedule distributions, and district profiles—was scattered across separate government portals with no unified search.

Engineering

Built a client-side directory using React 19, Three.js 3D boundary geometry, and D3 Geo projections. Indexed all 28 States, 8 Union Territories, and 786 administrative districts into pre-computed static datasets, enabling instant filtering without remote server queries.

Outcome

Directory covering all 28 States, 8 Union Territories, and 786 administrative districts with executive cabinet rosters, demographic filters, and Seventh Schedule distributions; deployed live on Firebase Hosting.

Hardest part

Rendering dense 786-district SVG boundary geometry smoothly on mobile screens without frame drops, resolved by pre-projecting coordinates with D3 Geo into static datasets.

IPL Mega Auction Platform

A real-time multiplayer auction room where users simulate franchise bidding for cricket squads.

Context

Simulating competitive cricket auctions across multiple connected devices causes purse overdrafts and duplicate high bids when users click simultaneously.

Engineering

Designed an event-driven bidding engine using Firebase Realtime Database with transaction validation guards. When multiple franchises bid at the same instant, client updates roll back automatically if remaining purse balance or roster limits are exceeded.

Outcome

Simulated 10-team live auction floor with Firebase Realtime Database: 10 concurrent bidder sessions, over 120 bids submitted, and 0 budget overdrafts recorded.

Hardest part

Resolving client-side optimistic UI state when simultaneous high bids arrived within milliseconds, handled by Firebase Realtime Database transaction guards that roll back invalid bids.
